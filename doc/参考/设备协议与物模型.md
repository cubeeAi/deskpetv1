# 设备协议与物模型

## 当前模型及并存差异

[DeskBuddy 模型](../deskbuddy-v1-thing-model.json)对应当前显示型设备，[服务实现](../../main/services/app_services.cpp)决定实际可执行范围。仓库还保留[通用 DeskPet 模型](../deskpet-v1-thing-model.json)作为历史产品资料；其中 move、speak、volume、碰撞等不能用于当前 DeskBuddy 能力声明，也不能直接覆盖当前产品。

Core 当前使用 cubee 前缀，而本固件 build_mqtt_topics 固定 pet。它构造 mqtt://host:port，不是 TLS 客户端；改变端口为 8883 不会自动启用 TLS。跨仓适配未完成，本次只记录事实，不修改协议、安全配置或业务实现。

## Topic 与信封

ClientId/username 使用设备 ID，password 使用该设备 secret。参数优先取 factory_nvs，缺项可回退编译期默认；没有有效 secret 或仍为占位值时禁用 MQTT。

| 方向 | Topic | QoS |
| --- | --- | --- |
| 订阅 | `pet/{deviceId}/cmd`、`pet/{deviceId}/resp` | 1 |
| 发布 | `pet/{deviceId}/telemetry` | 0 |
| 发布 | `pet/{deviceId}/cmd/ack`、`pet/{deviceId}/event`、`pet/{deviceId}/req` | 1 |

命令需要 schemaVersion=1、非空 type/reqId。最近 12 个 reqId 在执行前记入内存，包括之后失败的命令；重复回 DUPLICATE，不重放原执行结果，重启后不保证去重。MQTT PUBACK 是传输结果，业务完成看 cmd/ack 及后续遥测。

```json
{"schemaVersion":1,"reqId":"deskbuddy-brightness-example","type":"setBrightness","ts":1790899200,"payload":{"brightness":50}}
```

## 服务、属性与错误

| 服务 type | payload 与行为 |
| --- | --- |
| setBrightness | brightness 数值经当前实现转整数后检查 0–100，设置 OLED 亮度并上报 |
| setEmotion | emotion 经 emotion_to_mood 映射；支持值见[枚举转换](../../main/app/app_types.cpp)，不是任意文本 |
| setPage | page 字符串经 parse_page 转页面，再上报 |
| setWeatherConfig | city/latitude/longitude/timezone；经纬度接收字符串或数值，更新后位置与时区非空，保存并刷新天气 |
| setWeatherTheme | theme 经预设主题解析，保存后更新显示 |
| reboot | 安排延迟重启并回 DONE；不是重启完成证明 |

`writeProperty`、`ota.switch` 和未列出的服务回 UNSUPPORTED_TYPE。模型把 brightness/weatherTheme 标为 RW，并不意味着本固件支持通用 writeProperty。物模型与当前执行器仍需对接方逐项匹配。

| ACK code | 当前含义 |
| --- | --- |
| DONE | 当前处理分支完成，或重启已安排 |
| BAD_PAYLOAD | JSON、字段、数值范围或枚举不合要求 |
| DUPLICATE | 当前缓存已见 reqId，ok=false |
| INTERNAL_ERROR | 保存用户配置失败 |
| UNSUPPORTED_TYPE | 没有该命令分支 |

遥测直接上报 rssi、brightness、version、wifiConnected、configPortalActive、currentPage/currentMood、城市/经纬度/时区、weatherTheme、当前天气、weatherReady 和 weatherForecast。周期全量、变化差量；字段类型及枚举看模型 JSON，不能补出未上报的硬件数据。本实现没有结构化 versionInfo 和 OTA 安装链，version 字符串不是 OTA 对账事实。

事件为 touch、configPortalEntered、wifiConnectFailed、weatherRefreshFailed，使用 eventId/eventType/timestamp/params；主动请求用 getWeather 的 req/resp。服务端租户与设备归属由凭据解析，设备不能自己声明权限。

排查无响应先看前缀/TLS差异，再看 reqId、支持分支与参数；天气按请求生命周期定位，不通过重复发送掩盖 pending 或错误。示例仅供隔离验证，本轮没有执行 MQTT 命令。
