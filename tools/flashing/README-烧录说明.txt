Cubee 固件烧录说明

1. 请先安装 USB 串口驱动
   - 常见为 CH340 或 CP210x

2. 用 USB 数据线连接设备

3. 双击“一键烧录.bat”

4. 根据提示输入串口号，例如：
   COM7
   - 脚本会先自动列出当前检测到的 COM 口
   - 如果只检测到一个串口，也会先显示推荐值，再让你确认

5. 等待烧录完成
   成功后会提示：
   [OK] 烧录完成，请重新上电设备

注意事项：

- 请使用可传数据的 USB 线，只有充电功能的线无法烧录
- 烧录过程中不要断电、不要拔线
- 如果烧录包是完整版本，通常不需要额外安装 Python 或 esptool
- 只有在烧录包缺少内置运行时的情况下，才需要联系管理员重新打包
- 如果提示找不到串口，请检查：
  1) 驱动是否安装
  2) USB 线是否支持数据
  3) 设备是否正常上电
